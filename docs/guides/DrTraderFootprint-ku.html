ڕێبەری فووتپرینت

فووتپرینت ناوەوەی هەر مۆمێک (کەندڵ) نیشان دەدات: لە هەر نرخێکدا چەند گرێبەست مامەڵەی پێکراوە و کام لایەن هێرشبەرتر بووە، کڕیار یان فرۆشیار.

تیکی زێڕ: $0.10 بەهای هەر تیک: $10 Imbalance: 3 : 1 Value Area: 70%

فووتپرینت چییە؟

مۆمی ئاسایی تەنها چوار نرخ نیشان دەدات: کردنەوە، بەرزترین، نزمترین و داخستن. فووتپرینت مۆمەکە دەکاتەوە: بۆ هەر ئاستێکی نرخ، قەبارەی ئەو مامەڵانەی تێیدا کراون دەنووسێت و دابەشیان دەکات بۆ دوو بەش، فرۆشتنی هێرشبەر و کڕینی هێرشبەر.

کڕینی هێرشبەر واتە کڕیارێک کە چاوەڕێی نرخی باشتر نەکردووە و بە نرخی Ask کڕیویەتی. فرۆشتنی هێرشبەر واتە فرۆشیارێک کە بە نرخی Bid فرۆشتوویەتی. ئەم جیاکردنەوەیە لە داتای ڕاستەقینەی مامەڵەکانەوە دێت، بۆیە دەبێت Tick Replay چالاک بێت.

نموونەیەکی دوو مۆمی زێڕ، هەر ڕیزێک ٥ تیکە ($0.50). ژمارە زەردەکان بەشەکانی خوارەوە نیشان دەدەن.

خوێندنەوەی خانەیەک

هەر ڕیزێک یەک خانەیە بە شێوەی فرۆشتن × کڕین. ژمارەی لای چەپ و لای ڕاستی نیشانەی x هەمیشە بەم شێوەیەن:

فرۆشتنی هێرشبەرلە نرخی Bid
24x87
کڕینی هێرشبەرلە نرخی Ask

لەم نموونەیەدا لەو نرخەدا ٢٤ گرێبەست فرۆشراوە و ٨٧ گرێبەست کڕدراوە. واتە لێرەدا کڕیاران زۆر هێرشبەرتر بوون.

کۆکردنەوەی ڕیزەکان

لە چارتی ١٥ خولەکیدا هەر مۆمێکی زێڕ ٥٠ تا ٨٠ ئاستی نرخی هەیە. بۆ ئەوەی ژمارەکان بخوێنرێنەوە، ئیندیکاتۆرەکە خۆی چەند تیک لە یەک ڕیزدا کۆدەکاتەوە (بۆ نموونە ٥ تیک). کاتێک زووم دەکەیت، ڕیزەکان وردتر دەبنەوە. ئەمە لە ڕێکخستنی Ticks per row دەگۆڕدرێت (0 = خۆکار).

هێماکان و واتاکانیان

ژمارەی هەر کارتێک هەمان ژمارەی سەر وێنەکەی سەرەوەیە.

Imbalance چۆن دەژمێردرێت؟

بەراوردکردن خواروخێچە (Diagonal)، نەک ئاسۆیی. کڕیاری هێرشبەر نرخی Ask دەخوات کە یەک ئاست لە سەرووی Bid ە، بۆیە کڕین لە هەر ڕیزێکدا لەگەڵ فرۆشتنی ڕیزی خوارەوەی بەراورد دەکرێت، و فرۆشتن لەگەڵ کڕینی ڕیزی سەرەوەی.

نموونەی سەرەوە: 66 ≥ 3 × 15 = 45 ← Imbalance ی کڕین. نموونەی خوارەوە: 62 ≥ 3 × 14 = 42 ← Imbalance ی فرۆشتن. ڕیزی لێوار (سەرەوە و خوارەوەی مۆم) هاوبەشی خواروخێچی نییە، بۆیە Imbalance ی بۆ ناژمێردرێت.

خشتەی ئاماری خوارەوە

لە خوارەوەی چارتەکە، بۆ هەر مۆمێک ستوونێک هەیە. هەر ڕیزێکی خشتەکە ژمارەیەکی جیاواز نیشان دەدات:

ڕیزواتابەکارهێنان
Volکۆی قەبارەی مۆمەکەشینی تۆختر = قەبارەی زیاتر. مۆمە قەبارە زۆرەکان بە خێرایی دەدۆزیتەوە.
Deltaکڕینی هێرشبەر لێدەرچووی فرۆشتنی هێرشبەرسەوز = کڕیار زاڵ بووە، سوور = فرۆشیار زاڵ بووە.
Delta%Delta دابەش بە قەبارەهێزی ڕێژەیی پاڵەپەستۆ. +20% بەهێزترە لە +5%.
MaxD / MinDبەرزترین و نزمترین Delta لە ماوەی مۆمەکەدادەریدەخات کڕیار یان فرۆشیار لە ناوەڕاستی مۆمەکەدا چەندە پێشکەوتووە و پاشان گەڕاوەتەوە. MaxD ی زۆر بەڵام Delta ی کۆتایی کەم = کڕینەکان هەڵمژراون.
Tradesژمارەی مامەڵەکانی فرۆشتن × کڕینئایا پاڵەپەستۆکە لە چەند مامەڵەیەکی گەورەوە هاتووە یان لە زۆر مامەڵەی بچووک. ئەمە ژمارەی مامەڵەیە، نەک ژمارەی فەرمان (order).
CVDDelta ی کەڵەکەبوو لە سەرەتای دانیشتنەوەڕەوتی گشتیی پاڵەپەستۆی کڕین و فرۆشتن لە ماوەی ڕۆژدا.

چوار شێوازی باو

ئەم شێوازانە بەڵگەی ڕەفتاری کڕیار و فرۆشیارن. هیچ کامیان بە تەنها ئاماژەی کڕین یان فرۆشتن نییە.

بەردەوامبوونی ڕەوت

چەند Imbalance ی کڕینی لە سەر یەک (ناوچەی Stacked ی سەوز)، Delta ی پۆزەتیڤ و POC لە نیوەی سەرەوەی مۆمەکە.

خوێندنەوە: کڕیاران کۆنترۆڵیان بە دەستەوەیە و فرۆشیاران ناتوانن ڕایانبگرن.

هەڵمژین (Absorption)

بازنەی گەورەی فرۆشتن و ژمارەی فرۆشتنی زۆر لە بنی مۆمەکە، بەڵام نرخ دانابەزێت و مۆمەکە نزیک بەرزترین خاڵی خۆی دادەخرێت. مۆمی دواتر بەرز دەبێتەوە.

خوێندنەوە: فرۆشتنەکان لەلایەن کڕیارانی چاوەڕوانەوە (Limit) هەڵمژراون.

ماندووبوون (Exhaustion)

نرخ لوتکەیەکی نوێ دروست دەکات، بەڵام ژمارەی کڕین لە لوتکەدا زۆر بچووکە (3 x 0) و هێڵی پرتەقاڵی نییە. مۆمی دواتر بە Imbalance ی فرۆشتن دادەبەزێت.

خوێندنەوە: کڕیاری نوێ نەماوە بۆ بەرزکردنەوەی نرخ.

تاقیکردنەوەی ناوچە

نرخ دەگەڕێتەوە بۆ ناوچەیەکی Stacked ی پێشوو، دەچێتە ناوی بەڵام نایشکێنێت و مۆمەکە بە سێبەرێکی درێژی خوارەوە بەرز دادەخرێت.

خوێندنەوە: ناوچەکە وەک پشتگیری کاری کردووە. خاڵی بڕیاردانە، بە مەرجی مۆمی پشتڕاستکردنەوە.

ڕێکخستنەکان

لە پەنجەرەی Indicators (Ctrl+I)، DrTraderFootprint هەڵبژێرە. گرووپەکان بەم شێوەیەن:

گرووپچی تێدایە
01. Dataسەرچاوەی داتا (Auto = Tick Replay ئەگەر چالاک بێت). ژمارەی ئەو مۆمانەی فووتپرینتیان بۆ دەکێشرێت.
02. Footprintناوەڕۆکی خانە: BidAsk (گرێبەست)، TradeCount (ژمارەی مامەڵە)، Delta، Volume. ڕەنگکردن: ImbalanceOnly، DeltaHeat، VolumeHeat، ProfileBars. پانیی ستوون، هێڵی مۆم، POC، Value Area، مزایدەی تەواونەکراو.
03. Themeڕووکار: Dark، Light، Midnight یان Custom بە ڕەنگی دڵخوازی خۆت.
04. Imbalanceڕێژە (3 = ٣٠٠٪)، کەمترین قەبارە، ژمارەی Stacked، درێژکردنەوەی ناوچەکان تا شکان.
05. Bar Statisticsپیشاندان یان شاردنەوەی خشتەی خوارەوە و هەر ڕیزێکی.
06. Tapeبازنەی جێبەجێکردنە گەورەکان: پەنجەرەی کۆکردنەوە بە میلی چرکە و سنووری قەبارە.
07. Rows & Textتیک بۆ هەر ڕیزێک (0 = خۆکار)، بەرزیی ئامانجی ڕیز، قەبارەی فۆنت.

دەستپێکردن لە چارتدا

  1. چارتی GC (گرێبەستی چالاک) بە Tick Replayی چالاک بکەرەوە. چارتی 5 Minute بۆ فێربوون باشترە.
  2. DrTraderFootprint زیاد بکە و ڕووکاری Dark هەڵبژێرە. ڕەنگی پاشبنەمای چارتەکەش لە Chart Properties تاریک بکە.
  3. بۆ پانکردنەوەی مۆمەکان، تەوەری کات (خوارەوەی چارت) بەرەو ڕاست ڕابکێشە.
  4. بۆ بەرزکردنەوەی ڕیزەکان، تەوەری نرخ (لای ڕاست) بەرەو خوارەوە ڕابکێشە.
  5. ئەگەر ژمارەکان دەرناکەون، Target row height زیاد بکە یان Ticks per row بکە بە 5.

ئاگاداری

هیچ کام لەم هێمایانە بە تەنها ئاماژەی کڕین یان فرۆشتن نین. تەنها بەڵگەن لەسەر ڕەفتاری کڕیار و فرۆشیار و دەبێت لەگەڵ شوێنی نرخ (POC و VAH/VAL ی ڕۆژانە، ئاستە گرنگەکان) و پشتڕاستکردنەوەی جووڵەی نرخ تێکەڵ بکرێن.

ئەگەر داتاکە دواکەوتووە (Delayed) یان Tick Replay چالاک نییە، دابەشکردنی کڕین و فرۆشتن خەمڵاندنە و ورد نییە. بۆ مامەڵەی ڕاستەقینە پەیوەندی بە داتای ڕاستەوخۆ (بۆ نموونە Rithmic) پێویستە.
